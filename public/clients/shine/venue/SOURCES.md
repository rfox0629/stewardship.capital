# SHINE Founders Weekend venue photography

Every file in this directory derives from the public listing for the actual
Founders Weekend venue, the Spooner Lake Island Oasis:

https://www.classyrusticrentals.com/spooner-lake-island-oasis-orp5b6b84dx

Fetched 2026-08-24 at the founder's direction. Each derivative was resized,
compressed, and given a subtle uniform grade (saturation 0.90, contrast 1.03,
brightness 0.98) to sit with the Founders Weekend palette. Nothing in any
photograph was added, removed, or generatively altered.
